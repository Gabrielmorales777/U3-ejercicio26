# U3-ejercicio26
# Jerarquía de Animales y Comportamientos Sonoros

## Objetivo principal

Construir una jerarquía de clases en Java que represente diferentes especies de animales mediante herencia y sobrescritura de métodos.

## Descripción

Se implementa una clase base `Animal` con los atributos comunes nombre y edad, además de un método genérico para emitir sonidos.

A partir de esta clase se desarrollan las subclases `Perro`, `Gato` y `Pajaro`, que sobrescriben el método `hacerSonido()` para representar el sonido característico de cada especie.

Los constructores de las clases hijas utilizan `super()` para inicializar los atributos heredados.

## Conceptos aplicados

- Herencia
- Constructores
- Uso de `super`
- Sobrescritura de métodos (`@Override`)
- Polimorfismo
